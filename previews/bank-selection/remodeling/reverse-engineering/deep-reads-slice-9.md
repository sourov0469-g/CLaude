## 252 ★ · WebGPU Fluid Simulations — tympanus.net/codrops/2025/02/26/webgpu-fluid-simulations-high-performance-real-time-rendering/
Stack (Measured): raw WebGPU compute shaders (no Three.js in the sim projects), TypeScript+Vite in linked repos. This is an EXPLAINER, not a code tutorial — it publishes no shader code or solver constants; numbers below are its stated results + two details from its own linked WebGPU-Ocean repo README (labelled).
Demos (article links): WebGPU-Ocean (webgpu-ocean.netlify.app; MLS-MPM and SPH both implemented, toggleable; SPH appears to freeze on Mac) and WaterBall (waterball.netlify.app, fluid on a sphere, gravity to centre).
Mechanism: solver = MLS-MPM (Hu et al. 2018), hybrid particle/grid: P2G (scatter mass/momentum to grid) → grid update → G2P (gather velocities back). No particle–particle interaction ⇒ no neighbourhood search — the whole performance argument. WebGPU enabler: P2G scatter via compute atomicAdd; repo detail: WebGPU atomicAdd is 32-bit-int only, so particle data is fixed-point integers decoded × a constant, e.g. **1e-7**. Volume recalculated every step ⇒ large timestep — currently **2 sim steps per frame** ("a bit too large, occasionally explodes", author's words). SPH baseline: density/pressure from neighbours in fixed radius → pressure+viscosity forces → integrate; neighbour search via GPU fixed-radius NN algorithm.
Performance (Measured, test GPU = iGPU of AMD Ryzen 7 5825U): SPH ~30,000 particles real-time; MLS-MPM ~100,000 on iGPU, ~300,000 on decent discrete GPU.
Rendering = Screen-Space Fluid Rendering, 5 steps: render depth → render thickness (additive) → smooth both (bilateral/gaussian) → reconstruct normals from smoothed depth → shade reflection/refraction (thickness)/specular. WaterBall renders SSFR at HALF window resolution; particle size varies with simulated density; particles stretched along velocity; edges highlighted at depth discontinuities.
Mobile (Measured): WaterBall runs smoothly on a 6-year-old iPad Air 3 with the WebGPU flag on and particle count "small". Reduced-motion: none. Verdict: mechanism-study only — documents the MLS-MPM + SSFR route and its particle budgets; nothing here ships to a trade site.
