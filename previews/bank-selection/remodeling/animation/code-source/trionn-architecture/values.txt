The Architecture Behind Trionn — Coordinating GSAP, Three.js, Lenis and Web Audio (Codrops case study)
Source: article tympanus.net/codrops/2026/07/15/the-architecture-behind-trionn-coordinating-gsap-three-js-lenis-and-web-audio/ — the article IS the code source (all values below are quoted from its code excerpts). Site: trionn.com. Built over 4 months. No values.txt raw dump exists because there is no single demo file set; the article's excerpts are the measured record.

STACK (Measured)
- Next.js + React + Tailwind. GSAP + @gsap/react (useGSAP for lifecycle) at the centre; ScrollTrigger for pins/scrubs. Vanilla Three.js — deliberately NOT React Three Fiber — for direct control of one shared render loop and per-panel meshes. Lenis driven from gsap.ticker (single master clock). Swiper for testimonial/awards carousels. Web Audio API, all hero/footer sounds synthesized at runtime; About curtain/growl use recorded buffers. gsap.matchMedia() separates desktop/mobile animation logic. Reusable BlurTextReveal component centralises SplitText reveals (reduced-motion + GPU cleanup in one place).

COORDINATION ARCHITECTURE (Measured from article)
- One clock: gsap.ticker drives Lenis (lenis.raf inside the ticker) and the Three.js scenes; ScrollTrigger reads the same scroll state.
- Loader sequencing: hero layers are gated by a shared transitionReady flag so nothing animates until the page transition/loader clears; the hero headline uses delay 1.2 for the same reason. Non-critical work (services frame preloads) is deferred with requestIdleCallback.
- Scroll state: sections share one scrollProgressRef (0..1); the Services sequence uses NO ScrollTrigger at all — it remaps the shared progress per section.
- Audio: no explicit AudioContext.resume() routine is documented in the article; every sound is gesture-triggered (hover, hold, drag, pluck), synthesized at runtime except the About section's recorded curtain/growl assets. Sections communicate through tiny shared surfaces: the atmosphere context exposes only pulseSmoke() / getSmokeAnalyser() between the footer logo and the fog shader.
- Cross-section sequencing: the About lion reveal is fired by a CustomEvent "trionn:about-lion-start" plus a document.documentElement.dataset.trionnLionStart flag so a late-mounting listener still catches it; listener registered { once: true }.

PARAMETERS (Measured)
HEADLINE REVEAL (BlurTextReveal): SplitText type "chars, words, lines", smartWrap true. Set: autoAlpha 0, filter blur(12px), willChange "filter, opacity". Container: to blur(0), duration 0.5, at the delay. Chars: duration 0.8, stagger { each: 0.08, from: "random" }, ease power2.out. Usage delay 1.2. will-change removed on complete. Foreground text uses mix-blend-mode: difference over the canvas.
HERO SYMBOL IDLE: rotY += 0.0042/frame (0.0015 if prefersReducedMotion); rotX clamped to +/- PI/2; group rotation lerps toward target + mouse*0.22 with factor 0.06.
PANEL DRIFT: 3 arms, phase = shapeIdx * (2PI/3) (0/120/240 deg). driftX = sin(t*0.4 + phase) * 0.012; driftY = cos(t*0.35 + phase) * 0.008; driftZ = sin(t*0.3 + phase*1.5) * 0.006; all multiplied by (1 - explodeAmt).
MAGNETIC HOVER: raycast per frame only when mouse present (!== -9999) AND scrollProgress < 0.08 AND clickBurst < 0.05 AND introAmt < 0.08. First hit on a new panel sets _flash = 1.0 and plays audio.playHoverBeep() (once per panel entry). Flash decays x0.92/frame. envMapIntensity = 3.0 + f*1.6; clearcoatRoughness = max(0.01, 0.05 - f*0.035); transmission = 0.35 + f*0.32.
WELD SPARKS: enabled when in-section AND undrawAmt < 0.02 AND every line progress >= 0.995. Hit-test against 3 line paths at 14px tolerance. Burst = 5 + floor(rand*2) bolts (5-6); targets 1-2 other lines (50% get 1). Cooldown 0.04 + rand*0.06 s (0.04-0.10). Glow = layered THREE.Line, no bloom pass. Guide lines are drawn to an offscreen 2D canvas used as a texture, so hit-testing is 2D. Timing by frame counters, not GSAP.
HOLD-TO-BLAST: mousedown sets holding=true, holdTime=0, vibrateAmt=1.0, vibratePhase=0, clickBurst=0. Per frame holdTime += 1/60; charge phase is < 0.5 s; passing the threshold stops vibration and plays explode + whoosh once. vibrateAmt decays x0.88/frame; clickBurst ramps +0.02/frame to 1.0 (~50 frames). On release: vibrateAmt -= 0.08/frame, clickBurst -= 0.025/frame. explodeAmt = max(scrollProgress, hoverAmt, burstContrib, introAmt) where burstContrib counts only when scrollProgress < 0.15. Panel offset = max(0, explodeAmt - panel.delay) * 5.5 along explodeDir; rotation = spinAxis * spinSpeed * amt * PI. UI vibrate release CSS: transition transform 0.7s cubic-bezier(0.25, 0.46, 0.45, 0.94); transform perspective(600px) translate(0,0) rotateX(0).
SERVICES SEQUENCE: TOTAL = 371 WebP frames on a single <img>, src swapped only when the index changes; filenames frame_0001.webp (padStart 4). EXPLODE_START 0.35, EXPLODE_END 0.53, CARDS_START 0.56, CARDS_END 1.0. Frame index eased: videoIdx += (target - videoIdx) * 0.12. Preload in requestIdleCallback chunks of 20 with img.decode(). Headline glyphs measured per-char via Range API getBoundingClientRect. Particle speed: hero glyphs rand(0.05-0.15) * maxDim; other headlines rand(0.4-0.9) * maxDim; dirY = sin(angle) * rand(-1.0, 0.18). Cards: 6 cards; desktop pairs start 0.2 timeline units apart; X arc frac <= 0.5 ? sin(frac*PI) : 1; Y linear. At a pair's centre, SVG icon draws with DrawSVG "0%" -> "100%", duration 1.5, stagger 0.04, fired once per card via a Set. GSAP timeline built once per layout and scrubbed via .progress(explodeT). Stripe wipe: holdT = clamp((linear - holdStart) / (1 - holdStart)) scrubs a paused stripe timeline + next section yPercent slide (pattern reused in Vision/About/Gallery). Palette transitions black -> white inside the same progress value.
HELIX GALLERY: 9 cards. Path hPos(a) = (R*cos a, Y_START + a*pitchPerRad - dip(a), R*sin a); dip = DIP_A * exp(-d^2), d = (a - MID)/DIP_S (Gaussian). Cards vertex-deformed onto the curve per column per frame (wrapCardOnHelix, scalar math, no Vector3 allocations). ScrollTrigger pin start "top top", end += totalScroll; rendering only on onUpdate + a gated ticker (active window = section +/- 1 viewport). Hover raycast target scale 1.12 eased by lerp (hoverLerpK). Rounded corners in the fragment shader: SDF dist = min(max(q.x, q.y), 0) + length(max(q, 0)) - uRadius; alpha = 1 - smoothstep(-0.5, 0.5, dist); discard if alpha <= 0. warmUp: set all visible -> renderer.compile -> renderer.render -> restore visibility -> renderer.clear(); run at init AND after textures load.
FOOTER WIRE LOGO: each SVG stroke is a string. state.cycles = 2.2. note = DEFAULT_SCALE[i % len] * (i % 2 ? 1 : 0.5); intensity = i === 0 ? 0 : pow(i / (paths - 1), 1.25). Hover: amp = hoverAmp, speed = 18; gsap.killTweensOf(state); amp -> 0 and speed -> 0 over 0.9 s expo.out each; calls pluckFluteDreamy(note, intensity) and pulseSmoke(0.4). Wave path rebuilt per frame with 26 segments; envelope sin(PI*t); wobble sin(2PI*cycles*t + phase) along the perpendicular. Update only while amp > 0.02 or speed > 0.02; phase += speed * dt. Invisible hit-clone per stroke: stroke transparent, strokeWidth = max(12, strokeWidth * 18), pointer-events "stroke", forwards mouseenter to the real path.
PLUCK SYNTH: 3 sine oscillators at f, 2f, 3f. LFO 4.9 Hz into osc1.frequency (vibrato). Delay max 1.0 s, delayTime 0.14. Feedback gain ramps to 0.32 + intensity * 0.12 over 0.05 s. Loop: delay -> echo lowpass -> feedback gain -> delay.
FOG SHADER: single fullscreen fragment shader, FBM 3 octaves (amplitude starts 0.5, halves each octave; p = p * 2.1 + vec2(3.7, 8.3)). rise = T * 0.07. q = vec2(uv.x * aspect * 3.0, (1 - y) * 4.5 + rise). Domain warp 1.4 * fbm. Colour: mix(charcoal, ashGrey, pow(f, 1.0)) -> mix(lightGrey, pow(f, 2.2)) -> mix(hoverTint, H * 0.55 * f).
AUDIO-REACTIVE: AnalyserNode on the same graph; energy summed over bins 2..length*0.5; raw = sum / (length * 0.5 * 255); smoothed: freqEnergy += (raw - freqEnergy) * lerpFactor. morphOffset += (4.0 + freqEnergy * 16.0 + hoverBoost * 2.8) * dt.
LION REVEAL (About): depth-map fragment shader. mouse = (uMouseEase - 0.5) * vec2(2.0, -2.0). breathing = sin(uTime * 0.0012) * 0.5 + 0.5. amount = (0.03 + 0.012 * breathing) * uHover. disp = mouse * depth * amount. RGB split: r sampled at uv + disp * 0.16, b at uv - disp * 0.16. Cursor eased 0.07/frame.
CURTAIN (About): per-strip spring sp = -offY * 0.12; vel = (vel + sp) * 0.65; offY += vel. Neighbour coupling: sp = (overlap - offY[ni]) * 0.22; vel = (vel + sp) * 0.62. Drag warp = Gaussian envelope exp(-(dx^2) * SIGMA_INV) around the grab point (clickX = dragSeg / SEGS); py = restY + displacement * envelope[s]. Audio: curtain SFX loops only during a real drag; loopStart = min(0.1, dur * 0.1); loopEnd = min(1.5, dur * 0.5); random start offset. Growl gated on dragSpeed > DRAG_MOVE_PX, |offY| > CURTAIN_OPEN_PX and elapsed >= CURTAIN_LEAD_S. Release "thud" only if something actually played — a plain click stays silent.
SCATTER GALLERY ("Work hard. Play loud."): 11 photos in shuffled collision-safe slots (separate desktop/mobile position fractions per image). Rotation rand(-4, 4) deg; jitter +/-36 px. 10 off-screen start positions cycled by index; gap = max(vw, vh) * 0.72. Pinned timeline scrub 0.6; each item tween duration 1.2 at position index * 0.34. Stripe phase gated by animationEnd = GALLERY_VH / (GALLERY_VH + STRIPE_HOLD_VH) via onUpdate. Dominant colour: downsample to 72x72 canvas; skip pixels with alpha < 220, brightness < 25 or > 245, saturation < 12; buckets keyed by round(c/22)*22; winner = best count x vividness, averaged. Click pull-forward: inner to rotation direction * 4.5, scale 1.035, opacity 0.18, duration 0.34, then back over 0.56. Overlapping neighbours pushed x = dx * random(18, 34), rotation dx * random(1.4, 2.8), 0.34 out / 0.52 back. Images mounted client-only via useSyncExternalStore (server returns false), crossOrigin="anonymous".
CLOSING LESSON (article's own): build a shared canvasManager from the start — juggling multiple canvases by hand was the project's main friction.

READING (Inferred)
- The transferable core for a solo template builder: ONE master clock (gsap.ticker) driving scroll (Lenis), 3D and shader time; one shared scroll-progress ref instead of scattered ScrollTriggers; gate every hero animation behind a single "transition ready" flag; defer all heavy preloads to requestIdleCallback in fixed chunks; and keep cross-section coupling behind tiny named functions (pulseSmoke) rather than shared mutable state.
