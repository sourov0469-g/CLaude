# UI / UX Patterns — structure, weight, layout
Seeded 26 Oct 2026 from cross-site facts in analysis.md (24 opened entries). This is the thinnest part of Claude's pass — Batch 4 gap-fill weights it heaviest.

## Cross-site facts (Measured, 24 opened)
- **Smooth scroll:** Lenis on 14/24 — it is the default of this class of site. Wire Lenis raf to the GSAP ticker.
- **Stacks:** Next.js 5 · Nuxt 6 · Webflow 4 · WordPress 1 (LPAS won Awwwards SOTD on WordPress — proof our stack is not the ceiling).
- **Page length (screens):** Neutomni 23.8 · Belgrade Arbor 23.3 · FORMAT 20.9 · Nick Ho 14.1 · LPAS 11.8 · Odyssee 10.8 · ESR 8.5 · Signal-A 7.3. Service sites cluster ~8–12 screens; agency/studio pages run far longer.
- **Anti-patterns for a lead page (Measured):** 8/24 are scene pages that don't scroll normally; 5/24 open with a gate or long loader. Both = DO NOT USE where the job is phone calls.
- **Accessibility gap:** reduced-motion rules found in only 2 of 15 style-checked sites (Forge 7 rules, Interaction Library 5). Our builds ship reduced-motion support — that is a quality edge, not a chore.
- **Cursor:** hiding the system cursor is common at the top end (PixelVault 239 elements, Neutomni 171) — our pattern: small follower that reacts per background, system cursor kept usable (standing build rule).

## Section models worth stealing the STRUCTURE of (not the layout)
- **Credential as giant type** — ESR Bespoke: official-certification statement set oversized on white. For trades: licence / guarantee / years as the hero-adjacent statement.
- **Persistent Contact button** — ESR: appears top-right after the hero. Matches our sticky-CTA rule.
- **Horizontal sector panels** — LPAS (WordPress): video hero → horizontal panels per sector. Candidate structure for the 6-trade portfolio row on dentivax.com.
- **Case-study index rows** — Signal-A: mono micro-labels + mixed-weight giant type. Candidate for portfolio index.
- **Blueprint grid + logo strip** — Heron AI: ruled grid, crosshair corners, client logo strip, Barba transitions.
- **In-brand cookie banner** — Neutomni: brand type/colour, Reject as easy as Allow. OFFF: three equal-weight buttons.
- **Giant two-tone footer wordmark** — OFFF Forum.
- **Chapter colour change on a long scroll** — Belgrade Arbor, floating pill nav.

## Weight / hierarchy notes (to deepen in Batch 4)
- Heavy/light alternation is the rhythm: full-bleed video or giant type (heavy) → one oversized plain statement on white (light) → proof/stat blocks (medium). ESR and Odyssee both run this order.
- Mixed-weight giant type (Signal-A, Nick Ho giant number hero) creates hierarchy inside one line, not across many elements.
- Mono micro-labels carry the "system" feeling without extra graphics.
