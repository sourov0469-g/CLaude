Proof you can pick up.

Four facts as building blocks. Throw them, stack all four, or tap one to check it for yourself.

Each block is a fact you can check: focus a block and press Enter to see how to check it. To move it, press Space to pick it up, the left and right arrows to carry it, Space to set it down, Escape to put it back.

How it works

  • Drag a block to throw it
  • Stack all four for a surprise
  • Tap one to check it
