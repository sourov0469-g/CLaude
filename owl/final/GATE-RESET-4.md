## 7. Defects found and fixed in-session
1. **A count-up showed false numbers mid-flight:** "3.7 from 90+ reviews", a "4-year" warranty, "Founded 2010". That breaks the facts lock even for a split second. It was replaced by a masked rise of the true value, and a check now asserts that mid-reveal values equal the final ones.
2. **"Systems Plus" overflowed** into the BBB column. It now has its own smaller size and can wrap.
3. **Two `aria-label`s on plain `div` and `p` elements** (prohibited in ARIA 1.2) were removed; the visible text is the source.
4. **The test ran axe mid-animation,** giving false contrast failures at partial opacity. The runner now lets the section settle first (a test fix only).
