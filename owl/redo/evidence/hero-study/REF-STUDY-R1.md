# Round 1 reference study · hero mechanisms (frame by frame + code level), 2026-11-03

Tool: `owl/redo/evidence/hero-study.cjs` — opens the live site in Chromium at 1440×900, captures the hero at
t = 3.1 / 4.1 / 5.7 / 9.0 s untouched (`f-t*.jpg`), sweeps the cursor over five points (`f-cursor1-5.jpg`), hovers the
first button (`f-btn-hover.jpg`), then reads the page the way DevTools does: tag counts, canvases and the context type
each one asked for (`getContext` is wrapped before the page loads), `document.getAnimations()` (type, name, duration,
easing, target), globals (gsap, Lenis, THREE…), the hero buttons' computed styles and inner DOM, fixed
pointer-events:none followers, transformed layers, the hero's outer HTML, and the event listeners on window, document
and body through the DevTools protocol (`DOMDebugger.getEventListeners`). Output per site: `hero-study/<name>/`
(`sheet.jpg`, `code.json`). Montage of all heroes: `hero-study/ALL-heroes.jpg`. No anti-bot wall was met; nothing was
bypassed. Only techniques are taken; no asset, text, branding or artwork was copied.
